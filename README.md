## 不需要GPU的核验

```bash
python3 scripts/verify_results.py
```

该命令从公开逐题记录重算主表和同题20题表，检查2750条主复评分的答案哈希、上下文摘要对应关系，以及冻结查询特征的任务顺序。它不调用模型、不下载权重，也不重新启动服务器实验。

## 目录

- `rsi-memory/`、`external-memory/`：原方法源码；原项目提交`d62aa408a4e0b9515eed9313663a025a07b08497`。
- `experiments/`：服务器实际适配与运行脚本，保留版本目录；原调度器含历史截止时间/PID，不应直接照抄启动。
- `results/`：逐题生成答案、逐题评分、聚合结果、进度和检查记录。输入会话/查询/金标准解释不重新分发，改用任务ID与哈希。
- `audit/`：事件日志、请求/响应元数据、异常样例；不是包含完整输入提示的原始HTTP转储。
- `environment/`：服务器三套环境的实际依赖快照，不应合并成一个环境安装。
- `manifests/`：输入文件/候选池/源码/第三方版本的来源与哈希。

原始数据、模型权重、SQLite/向量缓存、完整会话输入和未公开论文不上传。本仓库可直接复算已有表格；**发布过程中没有再执行一次GPU冷启动重跑**，不宣称“一条命令精确重现全部模型输出”。

早期探索保留脚本与现有摘要，本公开包不是完整运行盘镜像；大型缓存、深层中间状态和原始输入未上传。当前主表及10/20同题诊断的逐题产物完整。
